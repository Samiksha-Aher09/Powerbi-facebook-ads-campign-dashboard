# Powerbi-facebook-ads-campign-dashboard
# Project Overview :- This project focuses on analyzing Facebook Ads campaign performance to measure marketing effectiveness and identify optimization opportunities.
  An interactive Power BI dashboard was built to track key advertising metrics such as ROI, CTR, impressions, clicks, ad spend, and conversions across demographics, campaigns, and time.
  The dashboard helps marketing teams and stakeholders make data-driven decisions by understanding user behavior, campaign efficiency, and audience performance.
# Objectives :- 
  - Evaluate overall campaign performance
  - Analyze ROI and Click-Through Rate (CTR)
  - Understand user engagement by age and gender
  - Track ad spend efficiency across campaigns
  -  Identify high-performing campaigns and audience segments
# Dataset Details
  - Source: Facebook Ads campaign data
  - Data Type: Marketing & Advertising Analytics

#Key Fields:
  - Campaign ID
  - Reporting Date
  - Impressions
  - Clicks
  - CTR
  - Ad Spend
  - Approved Conversions
  - Gender
  - Age Group
# Data Cleaning & Preparation
  - Removed duplicate and null records
  - Standardized date formats
  - Converted metrics into appropriate data types
  - Created calculated measures using DAX:
  - ROI
  - CTR
  - Total Ad Spend
  - Total Clicks
  - Total Impressions
# Dashboard Features
  * Key KPIs
      - ROI
      - CTR
      - Total Impressions
      - Total Clicks
      - Ad Spend
      - Approved Conversions

  * Visual Insights
      - CTR & Ad Spend trends by day
      - Ad Spend by Campaign ID
      - Click-Through Rate by Age Group
      - Gender-wise Click Distribution
      - Campaign-level performance comparison
  * Interactive Filters
      - Date range slicer
      - Campaign ID selector
      - Gender filter
      - Age group filter
  * Tools and Technologies
      - Power BI – Data visualization & dashboarding
      - DAX – Calculated measures & KPIs
      - Excel / CSV – Data preprocessing
# Key Insights
  - Certain campaigns delivered higher ROI with lower ad spend
  - Male audience contributed a higher share of total clicks
  - Age group 45–49 showed the highest CTR
  - Ad spend fluctuations directly impacted daily CTR trends
  - Campaign-level analysis revealed optimization opportunities
# Business Value
  - Helps optimize ad budget allocation
  - Improves targeting strategy based on demographic performance
